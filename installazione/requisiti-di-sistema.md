# Requisiti minimi di sistema

### Kimo Server

1. Hardware
   1. CPU: Intel Xeon QuadCore (4 core per server virtuale)
   2. RAM: 16 GB
   3. hard disk: 50 GB free
2. Software
   1. Windows Server  2019 / 2022 / 2025
      1. Internet Information Service role (IIS)
      2. Microsoft .Net Framework 4.8
      3. Microsoft Message Queue feature
   2. MongoDB 5.x
   3. Microsoft Sql Server 2019 (Kimo integrator) o postgreSql

### Kimo SFA

1. Hardware
   1. iPad Apple con iOS 13.x o superiore

### Kimo B2B

1. web: Google Chrome (ultima release stabile)
2. App Android: device con Android 8.1 o superiore
3. App iOS: device Apple con iOS 13 o superiore
